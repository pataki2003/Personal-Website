Projects / Multi-publication editorial platform

Szerkesztőség.app.

Three domains and brands — Golden Hour, Gastro House, and Pályaszög — run on one shared Next.js / Payload system. Szerkesztőség.app keeps editorial access separated by publication.

Status
Internal system serving three magazines
My role
Shared platform and editorial workflow
01 / The problem

The problem

Three publications need distinct identities and public domains, while editors need a consistent workflow and access limited to their own magazine.

02 / What I built

What I built

I built a shared Next.js / Payload system with tenant-based editorial access, common content management, and publication-specific presentation and features.

03 / How it works

How it works

Sign in → own magazine → draft → preview → publish → public magazine

04 / Key features

Key features

  • Tenant-based editorial access
  • Draft, preview, and publishing
  • Media, categories, and authors
  • Magazine-specific presentation and recipe features
05 / My role

My role

I shaped the shared platform structure, editorial journey, and the interfaces tailored to each publication.

06 / Technology

Technology

Next.js and Payload CMS; three separate public domains served by one shared system.

07 / Result / current status

Result / current status

The shared system provides the editorial backend for the three named magazines. This page does not link to its internal admin login.
